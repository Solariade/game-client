game-client · 五子棋与象棋 AI 对弈

一、启动
    双击 game-client.exe 即可。
    默认打开象棋棋盘（未安装象棋引擎时自动回到五子棋），棋种也可随时在右侧切换。
    首次启动会在程序目录自动创建 runtime/（日志与对局数据库），无需手动创建。

二、模型配置（可选）
    .env 已随包提供，可填写各模型的 API Key；不配置也能正常下棋，只是没有 AI 解说。
    字段说明见 .env.example，修改 .env 后需重启程序生效。

三、五子棋操作
    - 你执黑先行，点击棋盘交叉点预选落子；
    - 第一次点击出现虚拟棋子，可点击其它空位改选；
    - 再次点击同一虚拟棋子才真正落子；
    - Esc 或右键取消预选；
    - 绿色虚线光环是本地引擎给出的落子建议，不依赖大模型；
    - 右侧可选择解说模型、难度，并开关「落棋建议」。

四、象棋操作
    - 象棋是启动默认棋种；也可在右侧「棋种」下拉切换（对局重新开始，设置保持）；
    - 执红时红方在下方；执黑时棋盘自动翻转 180°，黑方在下方、己方棋子始终在面前；
    - 点击己方棋子选中：蓝色光环 + 绿色圆点标出空位落点，红环标出可吃子；
    - 默认点击标记直接走子；点击其它己方棋子可改选，Esc 或右键取消选子；
    - 可选虚拟棋子：在 .env 中设置 XIANGQI_VIRTUAL_PIECE=true 后，点击标记先出现
      虚拟棋子（吃子时外圈另加红环），再次点击同一虚拟棋子才真正走子；点击其它
      标记可改选落点；Esc 或右键先取消虚拟棋子（选子保留），再按一次取消选子；
    - 最后一手会用红色标记标出起点与终点；建议同样标出起点与终点；
    - 被将军一方的将/帅显示红色警示环，状态栏同步提示「将军！」；
    - AI 每步后在「AI 分析」面板显示一行引擎评分（如「红方优 0.36 兵」）；
    - 将死或困毙时高亮输方的将/帅，状态栏注明取胜原因；
    - 「执红」含义与五子棋「执黑」相同：选择谁先行。

五、悔棋
    - 点击设置区的「悔棋」按钮或按 Ctrl+Z；
    - 正常对局撤销一回合（你的上一步与 AI 的应对），回到你走棋的轮次；
    - 终局后悔棋会撤销致胜一步并清除对局结果，可继续对弈；
    - AI 思考中不能悔棋；重新开局后不可悔到上一局。

六、象棋引擎安装（本包未内置时）
    棋种下拉中没有「象棋」表示未安装引擎，安装方法：
    1. 打开 https://github.com/official-pikafish/Pikafish/releases 下载
       Windows 版（不确定 CPU 型号就选 universal 版）；
    2. 解压后把 pikafish.exe、pikafish.nnue 与许可文件一起放入
       assets/engines/ 目录（详见该目录下的「下载指引.txt」）；
    3. 重启程序即可。引擎为 GPL-3.0 开源项目，不入本分发包。

七、文件说明
    game-client.exe    主程序
    assets/            图标与图片资源，必须与 exe 一起保留
    assets/engines/    象棋引擎 Pikafish 的安装位置（可选，含指引文件）
    .env               模型 API Key 配置
    .env.example       配置模板
    runtime/           日志与对局数据（首次运行自动创建）
    VERSION.txt        版本与构建信息
    LICENSE            开源许可证
    使用说明.txt       本文件

八、常见问题
    - 右侧显示「解说不可用」：检查 .env 中的 Key、网络与模型名；
    - 棋种下拉没有「象棋」：按第六节安装 Pikafish 引擎；
    - 「AI 出错，可点击重新开局」且正在下象棋：多为引擎文件缺失或
      权重未与 exe 同目录，参见 assets/engines/ 下的指引；
    - 不想联网：不配置任何 Key 即可，走棋完全由本地引擎完成；
    - 日志位置：runtime/log/app.log。
