game-client · 五子棋 AI 对弈学习

一、启动
    双击 game-client.exe 即可。
    首次启动会在程序目录自动创建 runtime/（日志与对局数据库），无需手动创建。

二、模型配置（可选）
    .env 已随包提供，可填写各模型的 API Key；不配置也能正常下棋，只是没有 AI 解说。
    字段说明见 .env.example，修改 .env 后需重启程序生效。

三、操作
    - 你执黑先行，点击棋盘交叉点预选落子；
    - 第一次点击出现虚拟棋子，可点击其它空位改选；
    - 再次点击同一虚拟棋子才真正落子；
    - Esc 或右键取消预选；
    - 绿色虚线光环是本地引擎给出的落子建议，不依赖大模型；
    - 右侧可选择解说模型、难度，并开关「落棋建议」。

四、文件说明
    game-client.exe    主程序
    assets/            图标与图片资源，必须与 exe 一起保留
    .env               模型 API Key 配置
    .env.example       配置模板
    runtime/           日志与对局数据（首次运行自动创建）
    VERSION.txt        版本与构建信息
    LICENSE            开源许可证
    使用说明.txt       本文件

五、常见问题
    - 右侧显示「解说不可用」：检查 .env 中的 Key、网络与模型名；
    - 不想联网：不配置任何 Key 即可，走棋完全由本地引擎完成；
    - 日志位置：runtime/log/app.log。
